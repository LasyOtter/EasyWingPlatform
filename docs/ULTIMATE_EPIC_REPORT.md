## 🚀 快速开始

```bash
# 1. 启动 Redis
docker run -d --name redis -p 6379:6379 redis:7-alpine

# 2. 设置环境变量
export OPENAI_API_KEY=your_key

# 3. 启动服务
cd easywing-platform-ai
mvn spring-boot:run

# 4. 测试基础功能
./scripts/test-all-features.sh

# 5. 测试多模态
curl -X POST http://localhost:8082/api/v1/ai/multimodal/process

# 6. 测试代码执行
curl -X POST http://localhost:8082/api/v1/ai/sandbox/execute \
  -d '{"code":"print(2+2)","language":"python"}'

# 7. 查看成本报告
curl http://localhost:8082/api/v1/ai/cost/report/default

# 8. 查看监控面板
curl http://localhost:8082/api/v1/ai/monitoring/dashboard
```
