# 企业级 AI 对话平台实施清单

依据 `LibreChat企业级AI对话平台_PRD.md`，按当前 Spring Boot 微服务架构拆分。仓库已有的 Provider、Agent/Tools/Skills、会话管理、OAuth2 Resource Server、Redis、Actuator 和 springdoc 能力作为基线，不另建 Node 前端，也不重写已有实现。

## P0：本次交付与优先顺序

| 顺序 | 能力 | 已有基线 | 本次实现 / 当前状态 |
| --- | --- | --- | --- |
| 1 | 模型统一接入与 Custom Endpoints | OpenAI、Anthropic、Google Provider 与统一 `AiProviderRegistry` | 增加 OpenAI-compatible 动态 Provider；支持 YAML 启动配置及管理员运行时增删，模型可进入统一列表并用于聊天。运行时变更仅存当前实例，需以配置管理持久化。 |
| 2 | 对话、模型切换与流式输出 | Chat Completions、SSE Agent、SessionManager | 修复 Provider 流式路由；OpenAI/Anthropic/Google 采用 SSE 流解析。会话增加模型、消息及租户信息；新增会话聊天、切换模型、编辑用户消息后重提、继续生成。Session API 从 JWT 取用户身份并按用户/租户隔离；修复 Redis 用户会话索引。 |
| 3 | MCP 工具 | MCP 请求/响应 DTO 与基础 HTTP Client | 增加受配置约束的服务器目录、Bearer Token、工具发现/调用 API；发现的工具注册到现有 Agent ToolRegistry，可被 Agent 调用。支持 stdio transport（`McpServerConfig.TYPE_STDIO`，子进程 JSON-RPC + 协议握手/能力协商）与 HTTP transport；服务器目录按租户与角色授权，仅授权租户可见可调用。 |
| 4 | Skills | 技能注册、执行器、推荐与链式执行 | 增加 MANUAL/AUTO/ALWAYS_ON 模式；提示词型技能可手动或自动调用模型，常开指令注入普通对话和 Agent 请求。技能管理限制管理员。技能目录持久化到内存或 Redis（`easywing.ai.skill.storage-type`），`SkillRegistry` 启动时先恢复持久化定义再播种内置技能，管理员对内置技能的启停与配置修改不会被覆盖。 |
| 5 | Subagents | 已有 `TaskDecompositionAgent`，子任务独立构造 AgentRequest | 暴露 `/subagents/delegate` API，并应用常开 Skills。 |
| 6 | 认证、安全与注册开关 | RS256 JWT、登录/刷新/吊销、角色和租户 Claim、网关限流 | 增加邮箱格式账号注册端点，默认由 `ALLOW_REGISTRATION=false` 关闭；开启后仅授予普通用户角色。新增 OAuth2/OIDC 外部登录（`easywing.auth.oauth2.enabled=true`，显式端点配置，不做 issuer 自动发现）与 LDAP 绑定认证（`easywing.auth.ldap.enabled=true`，先按过滤器搜索 DN 再绑定）；外部用户本地密码登录被拒绝。用户库持久化到 Redis（`easywing.auth.user-store=redis`），用户名/邮箱索引与播种幂等标记使多实例共享同一份用户数据；内置账号仅播种一次。邮箱验证与密码恢复流程（`TokenController` 的验证/忘记密码/重置密码端点 + 可插拔 `MailNotifier`，SMTP 经环境变量注入，默认仅记日志）。Trace/缓存/模型配置管理 API 限管理员；会话及记忆 API 根据 JWT 做用户/租户隔离。 |
| 7 | 运维与接口 | Actuator health、Prometheus、springdoc/OpenAPI | 沿用现有探针和 OpenAPI 配置；生产 profile 的会话/记忆/技能/用量账本/追踪存储切到 Redis。成本账本可持久化到 Redis（`easywing.ai.usage.storage-type=redis`），Hash 存记录本体、ZSET 按时间维护顺序并按 `max-records` 淘汰最旧记录，多实例共享同一份 Token/成本视图。 |
| 8 | Agent 定义管理 API | `AgentDefinition` 数据模型、Provider 路由 | 新增 `agentdef/` 包：`AgentDefinition`/`AgentDefinitionRequest`/`AgentDefinitionShareRequest`/`AgentVisibility`（PRIVATE/USER/GROUP/PUBLIC）、`AgentDefinitionStore`/`InMemoryAgentDefinitionStore`/`RedisAgentDefinitionStore`（`easywing.ai.agent-def.storage-type`）、`AgentDefinitionService`、`AgentDefinitionController`。端点 `/api/v1/ai/agents`：列举/详情/创建/更新/删除 + `POST|DELETE /{id}/share`，全部按 JWT 用户 + 租户做归属校验，被共享用户/群组与 PUBLIC 可读取，跨用户或跨租户统一 404。机器客户端走 `/admin/**`（`scope=agent-management`，client_credentials，`easywing.auth.oauth2.machine-clients`）。执行链路已接入：`/agent/execute`、`/subagents/delegate`、`/agent/execute/stream` 在执行前按 `agentId` 应用定义（`systemPrompt` 前置、`model` 回填、`tools` 白名单、`skills` 提示词前置），ReAct / Streaming / Function Calling / Planning 均按白名单过滤并拒绝越界工具；未命中定义原样返回，命中但不可读返回 404。WebSocket `/ws/agent` 走同一套逻辑：握手阶段由 `WebSocketTokenInterceptor` 校验令牌并把 `Jwt` 写入会话属性，执行时按该已校验身份应用定义；未携带令牌（`easywing.ai.websocket.require-token=false`）时不套用定义，避免信任客户端上报身份造成越权。列举排序在 `updatedAt` 相同（同一毫秒创建）时以 `id` 倒序兜底，保证多实例与重复执行下顺序稳定。 |

## 后续优先级

### P0 尚缺的生产集成

- OpenAI Responses API 已提供专用 Provider（`OpenAiResponsesProvider`，`easywing.ai.responses.enabled=true` 开启，`POST /v1/responses`，`input`/`output_text`/`max_output_tokens`/`response.output_text.delta` 事件均适配，默认关闭，密钥仅经 `RESPONSES_API_API_KEY` 等环境变量注入）。Vertex AI（Gemini on Vertex）已提供专用 Provider（`VertexAiProvider`，`easywing.ai.vertex.enabled=true` 开启，OAuth2 访问令牌鉴权，`easywing.ai.vertex.base-url` 指向 `.../publishers/google/models`，请求体与响应解析与 Google AI Studio 共用 `GeminiProtocol`，默认关闭，令牌仅经 `VERTEX_AI_ACCESS_TOKEN` 注入）。AWS Bedrock 已提供专用 Provider（`BedrockAiProvider`，`easywing.ai.bedrock.enabled=true` 开启，`BedrockProtocol` 适配 Converse 线协议，走 `BedrockRuntimeAsyncClient` 流式，支持 `toolChoice`/`StopReason`/`TokenUsage` 映射，默认关闭，凭据仅经 `BEDROCK_ACCESS_KEY`/`BEDROCK_SECRET_KEY` 等环境变量注入）。当前可通过 OpenAI-compatible 自定义端点接入兼容服务，Azure OpenAI 已有专用 Provider。
- 多实例共享的 Trace：已完成。DebugService 改为经 `TraceStore` 读写追踪快照，`InMemoryTraceStore` 为默认本地实现，`RedisTraceStore`（`easywing.ai.trace.storage-type=redis`，生产 profile 默认）用 Hash（`ai:trace`）存本体、ZSET（`ai:trace:ts`）按开始时间维护顺序并按 `max-records`（下限 100）淘汰最旧记录，多个 AI 实例共享同一份 Agent 执行链路，`/debug/traces` 查询到的是全局数据。终态（完成/失败）时经 `AiTraceExporter` SPI 导出：`NoOpAiTraceExporter`（`easywing.ai.trace.exporter=none`，默认，不导出）、`LangfuseTraceExporter`（`langfuse`，POST `{base-url}/api/public/ingestion`，Langfuse v2 `trace-create`，Basic Auth 由 `LANGFUSE_PUBLIC_KEY`/`LANGFUSE_SECRET_KEY` 注入，密钥不完整时降级跳过）、`OtelAiTraceExporter`（`otel`，复用平台 `Tracer` 输出 `easywing.ai.agent` span，属性键 `easywing.ai.*`）。导出实现不得抛出，异常只告警，不影响主流程。
- 技能/用户的管理界面（本阶段不创建独立前端工程，能力经 REST API 提供）。

### P1

- 对话 Fork/分支及分支差异比较：已完成。`ConversationSession` 增加 `parentSessionId`/`forkedAtMessageIndex`；`SessionForkService`（经 `SessionManager`，内存与 Redis 存储通用）提供 `fork`（按消息下标复制，越界自动收敛，消息对象深拷贝避免跨会话别名）、`branches`（按用户+租户过滤直接子会话）、`diff`（按消息下标逐位对齐，产出 `UNCHANGED`/`EDITED`/`ADDED`/`REMOVED` 条目与计数）。端点：`POST /api/v1/ai/sessions/{id}/fork`、`GET /api/v1/ai/sessions/{id}/branches`、`GET /api/v1/ai/sessions/{id}/diff?otherSessionId=`，均以 JWT 用户与租户做归属校验。
- RAG 与文件对话：已完成。`RagService.Document` 增加 `userId`/`tenantId` 归属，入库时写入向量块 metadata；`RagRequest` 增加 `userId`/`tenantId`，`query()` 改用 `searchWithFilter` 并合并请求 `filter` 与归属（修复此前 `filter` 字段未生效的缺陷）。新增 `DocumentRecord`/`DocumentStore`/`InMemoryDocumentStore` 文档目录（与向量存储分离，支撑按用户/租户列举与删除，进程内存实现，重启丢失）。新增 `FileDocumentService`：白名单扩展名（文本类 40+ 种）、单文件 5MB、解码后 100 万字符上限、NUL 二进制拒绝、UTF-8 校验、文件名 basename 防穿越、归属校验与级联删除。端点：`POST /api/v1/ai/rag/documents/upload`（multipart `file` + 可选 `title`）、`GET /api/v1/ai/rag/documents`、`GET /api/v1/ai/rag/documents/{documentId}`、`DELETE /api/v1/ai/rag/documents/{documentId}`；`/rag/query` 在携带 JWT 时按用户与租户限定检索范围。`spring.servlet.multipart` 限制 5MB/6MB。
- 隔离代码沙箱：已完成。`CodeExecutionSandbox`（`sandbox/`）覆盖 PRD 要求的语言：Python、JavaScript、TypeScript（`tsc` 编译为 JS 后交 Node 执行）、Go、C、C++（含 `c++` 别名）、Java、PHP、Rust、Fortran，共 10 个语言标识。安全边界：临时目录隔离 + 进程超时（按语言 `timeoutMultiplier` 放大）+ 输出上限 + 分级危险调用检查（进程执行/反射/退出等高危项无条件拦截；`import os` / `java.io` / `import socket` 等仅在对应能力关闭时拦截）+ 网络/文件系统默认关闭。**默认不装配**（`easywing.ai.sandbox.enabled=false`），启用需显式配置且密钥/工具链由环境提供。文件能力：`POST /api/v1/ai/sandbox/execute` 除 JSON 外还支持 `multipart/form-data` 上传输入文件（默认数量 8 / 单文件 1MB / 总量 2MB，均可配），文件名收敛为安全 basename（拒绝空名、`..`、超长）；程序产生或修改的文件以 `outputFiles`（name/size/mediaType/base64/truncated）返回，可直接下载。`easywing.ai.sandbox.*` 由新增 `SandboxProperties` 绑定（mode/maxExecutionTime/maxMemoryMB/maxOutputSize/allowNetworkAccess/allowFileSystemAccess 及上述文件限额）。已暴露 REST：`GET /api/v1/ai/sandbox/languages`（未启用返回 503）、`POST /api/v1/ai/sandbox/execute`（JSON 与 multipart 两种；`@Valid` 校验 code/language，支持 `allowFileSystemAccess`/`allowNetworkAccess`/`maxExecutionTime` 请求级覆盖；不支持的语言返回 400 且带语言名；执行失败返回 400 + `ExecutionResult.error`）。注意：当前隔离为 ProcessBuilder 子进程级，非容器边界，类注释已说明生产应改用容器。
- 联网检索流水线：已完成。新增 `search/` 包，三段可替换接口 `SearchProvider` / `ContentFetcher` / `ResultReranker`（默认 `IdentityReranker`）；`SerperSearchProvider`（`POST {base}/search`，`X-API-KEY`，解析 `organic[]`）、`HtmlContentFetcher`（仅 http/https，拒绝 loopback/链路本地/IPv6 ULA 等内网地址，HTML→纯文本，大小与字符上限）、`JinaReranker`（`POST {base}/rerank`，`Bearer`，按 `relevance_score` 回写 score）；`WebSearchPipeline` 编排：关闭返回 404、无 provider 返回 400、按 `fetchLimit` 保序抓取、重排、可选经 `AiProviderRegistry` 生成答案（上下文上限 6000 字符）。配置 `easywing.ai.web-search.*` 默认关闭，密钥仅经 `SERPER_API_KEY`/`JINA_API_KEY` 注入。端点 `POST /api/v1/ai/search`。
- Artifacts：已完成。新增 `artifact/` 包：`ArtifactExtractor` 从会话消息提取 `html` / `react` / `mermaid` 围栏代码块（跳过不支持语言与过短代码），`Artifact`（类型 HTML/REACT/MERMAID + 确定性 id），`ArtifactService` 按会话归属（userId + 规范化租户）列举/读取，并导出 Mermaid 为自包含 SVG（`foreignObject` + mermaid.js CDN，XML 转义）；PNG 导出明确返回 400（需浏览器渲染）。端点 `GET /api/v1/ai/sessions/{id}/artifacts`、`GET .../artifacts/{artifactId}`、`GET .../artifacts/{artifactId}/export`。

### P2

- 会话共享链接（PRD 4.7 / 5.2）：已完成。新增 `session/ShareLink`（随机 48 位十六进制令牌、sessionId、userId、tenantId、createdAt、expiresAt、revoked、maxAccesses、accessCount）、`ShareLinkStore`/`InMemoryShareLinkStore`（默认）/`RedisShareLinkStore`（`easywing.ai.share.storage-type=redis`，Hash `ai:share-links` 多实例共享）、`ShareLinkProperties`（前缀 `easywing.ai.share`）、`ShareLinkService`。创建/列举/撤销按 JWT 用户+租户做归属校验；公开读取 `GET /api/v1/ai/shared/{token}` 返回只读视图（不含 userId、消息元数据），并做每令牌每分钟固定窗口限流（超限 429）。过期、撤销、访问次数耗尽统一返回 404，不泄露资源存在性。功能默认关闭（`easywing.ai.share.enabled=false`），`defaultTtlHours`/`maxTtlHours`/`maxLinksPerSession`/`rateLimitPerMinute`/`maxMessages` 可配。AI 服务 `easywing.security.public-paths` 与网关 `easywing.gateway.jwt.ignore-paths` 均已放行 `/api/v1/ai/shared/**`（令牌即凭据）。端点：`POST /api/v1/ai/sessions/{id}/share`（body 可选 `ttlHours`、`maxAccesses`）、`GET /api/v1/ai/sessions/{id}/shares`、`DELETE /api/v1/ai/shares/{shareId}`、`GET /api/v1/ai/shared/{token}`。
- Prompt 库：已完成。新增 `prompt/` 包：`PromptDefinition`、`PromptStore`/`InMemoryPromptStore`/`RedisPromptStore`（`easywing.ai.prompt.storage-type=redis` 多实例共享）、`PromptService`。变量占位符 `{{变量名}}`（支持中文，提取时 `trim`），缺失变量返回 400；CRUD 与渲染均按用户+租户隔离。端点 `/api/v1/ai/prompts` CRUD 与 `/prompts/{id}/render`。
- 上下文用量面板（PRD 4.8）：已完成。新增 `ContextUsageService`，把单会话上下文拆成指令（system）/对话（user、assistant）/工具（tool 角色 + assistant 的 toolCalls/toolCall 参数）/缓存（消息 metadata 的 `cacheReadTokens` 等）四部分，结合 `ModelInfo.contextWindow`/`maxOutputTokens` 给出剩余额度与占用比例，成本按模型单价估算并叠加 `UsageLedger` 中该用户/租户/模型的已计费成本。未知模型回退 `easywing.ai.context-usage.default-context-window`（默认 128000）。端点 `GET /api/v1/ai/sessions/{id}/context-usage`、`GET /api/v1/ai/context-usage`、`GET /api/v1/ai/admin/context-usage`（管理员）。
- 图像能力（PRD 4.6）：已完成。多模态理解真实支持 TEXT+IMAGE：`MultiModalService` 重写为把图片作为视觉内容块交给视觉模型（`ImageUrl` 支持 URL 与 base64，base64 按魔数探测 png/jpeg/gif/webp；OpenAI/Anthropic/Gemini 各自 formatter 序列化，`detail` 可配），AUDIO/VIDEO/DOCUMENT 返回 400 而非模拟数据。图像生成/编辑新增 `ImageGenerationService`：OpenAI 兼容 `POST /images/generations`、multipart `POST /images/editions`，默认 `b64_json`，prompt 上限 16000 字符、单图 10MB、`n` 上限 4，端点不可用时返回 503。配置 `easywing.ai.multimodal.*`（默认开启）与 `easywing.ai.image-generation.*`（默认关闭）。端点 `POST /api/v1/ai/multimodal`、`/image/generate`、`/image/edit`、`GET /image/models`。PRD 中 Stable Diffusion / Flux / 任意 MCP 出图未纳入，需接入对应 Provider 或 MCP server。
- Web 对话 UI、多语言：未完成。按仓库约束，本阶段不创建独立前端工程；上述能力均通过 REST 提供，由既有 `easywing-ui` 或调用方对接。
- 按需手动压缩上下文：已完成。新增 `SessionCompactionService`（作用于持久化 `ConversationSession`，与仅处理内存 `ConversationContext` 的 `ContextCompressor` 互补）：保留全部 system 消息与最近 N 条消息，把更早的历史交给模型生成中文摘要，无可用模型或调用失败时回退到规则摘要；压缩后写回会话并更新 `messageCount`/`updatedAt`。预算与保留条数可用请求参数覆盖，否则取 `easywing.ai.compression.target-tokens`/`keep-last-messages`；功能关闭或已低于预算时返回 `compacted=false` 及原因，不产生额外模型调用。端点 `POST /api/v1/ai/sessions/{id}/compact`（body 可选 `targetTokens`、`keepLastMessages`），按 JWT 用户与租户做归属校验。

## 关键配置

- `easywing.ai.custom-endpoints.<id>`：`enabled`、`base-url`、`api-key`、`models`。
- `easywing.ai.mcp.servers.<name>` 与 `easywing.ai.mcp.server-tokens.<name>`：MCP HTTP 地址及可选 Bearer Token；`type=stdio` 时用 `command`/`args` 启动子进程。
- `easywing.ai.session.storage-type=redis`、`easywing.ai.memory.type=redis`、`easywing.ai.skill.storage-type=redis`：生产 Redis 会话/记忆/技能目录。
- `easywing.ai.prompt.storage-type=redis`：多实例共享 Prompt 库；`memory` 仅本地开发。
- `easywing.ai.share.*`：`enabled`（默认 false）、`storage-type`（memory/redis）、`default-ttl-hours`（168）、`max-ttl-hours`（720）、`max-links-per-session`（5）、`rate-limit-per-minute`（30）、`max-messages`（500）。
- `easywing.ai.agent-def.*`：`enabled`（默认 true）、`storage-type`（memory/redis）、`default-visibility`、`max-tools-per-agent`、`max-skills-per-agent`、`max-shared-users`、`max-shared-groups`；机器客户端另见 `easywing.auth.oauth2.machine-clients`（`client-id`/`client-secret`/`scopes`）。
- `easywing.ai.workspace.*`：`enabled`（默认 false）、`storage-type`、`base-dir`（缺省 `~/easywing/workspaces`）、`max-file-size`、`max-files-per-workspace`、`max-tree-depth`、`max-path-length`、`max-workspaces-per-user`、`allow-bash`（默认 false）、`bash-timeout-ms`、`bash-max-output-size`、`admin-scope`（默认 `workspace-management`）。
- `easywing.ai.context-usage.default-context-window`：模型目录缺 `contextWindow` 时的兜底窗口。
- `easywing.ai.multimodal.*`：`enabled`（默认 true）、`default-model`、`detail`（high/low）。
- `easywing.ai.image-generation.*`：`enabled`（默认 false）、`provider` / `default-model` / `models`、`default-size`、`default-n` / `max-n`、`timeout-ms`；密钥仅经环境变量注入。
- `easywing.ai.compression.target-tokens` / `keep-last-messages`：手动压缩的默认预算与完整保留条数。
- `easywing.ai.trace.storage-type=redis` / `easywing.ai.trace.max-records`：Trace 存储后端与容量上限（下限 100）。
- `easywing.ai.trace.exporter=none|langfuse|otel`：终态 Trace 导出器，默认 `none`（关闭）；`langfuse` / `otel` 需显式开启。
- `easywing.ai.langfuse.base-url` / `public-key` / `secret-key` / `timeout-ms`：Langfuse 导出目标与凭据，仅经 `LANGFUSE_*` 环境变量注入。
- `easywing.otel.*`（平台既有）：OTLP 导出端点等；`easywing-platform-bom` 已把 `opentelemetry-bom`（1.59.0）前置到 `spring-boot-dependencies` 之前，避免被 Boot 内置的 1.49.0 覆盖而与 `opentelemetry-spring-boot-starter` 2.25.0 冲突。`easywing-observability` 的 `otelTextMapPropagator` 标 `@Primary` 并组合 W3C TraceContext + Baggage + Jaeger，避免与 Boot 的 `textMapPropagatorWithBaggage` 并存时按类型注入歧义导致服务启动失败（已实测 AI 服务可启动）。
- `easywing.auth.user-store=redis`：共享用户库；`memory` 仅用于本地开发（默认，重启丢失）。
- `ALLOW_REGISTRATION=false`：默认关闭注册。
- `easywing.auth.oauth2.*` / `easywing.auth.ldap.*`：默认关闭，密钥经环境变量注入。
